# 计算机知识库

一个自动扫描的知识库网页：站点启动时递归读取 `知识库/` 目录，把里面的 Markdown 自动变成页面分类与文章。你只需要往目录里放文件，不用手写配置。

## 环境要求

- Node.js（建议 ≥ 14）
- 无第三方依赖，**不需要** `npm install`

## 运行启动

在项目根目录启动服务器：

```powershell
node server.js
```

启动成功后终端会打印：

```text
Knowledge base running at http://localhost:4173
```

浏览器访问 <http://localhost:4173> 即可。

自定义端口（可选）：

```powershell
$env:PORT = 8080; node server.js
```

停止服务：在终端按 `Ctrl + C`。

### 常见问题

- `Error: listen EADDRINUSE: address already in use :::4173`：端口被占用。关掉占用端口的进程，或用 `$env:PORT` 换端口启动。
- 页面提示“无法加载 config.json”：不要直接双击 `index.html` 打开，必须通过本地服务器地址访问。
- 新增/修改了 `知识库/` 内容但页面没变化：分类与文章列表在每次请求 `config.json` 时实时扫描，刷新浏览器即可，无需重启服务器。

## 目录即配置

`知识库/` 下的每个一级文件夹会变成一个分类，分类下按文件夹层级自动分组。每个 `.md` 文件就是一篇文章：

- 标题取 Markdown 的第一个 `#` 标题，没有则用文件名。
- 摘要取正文第一段。
- 更新时间取文件修改日期，首页“最近更新”会自动排序。
- 与文章同目录（含子目录）的 `.go` 源代码会自动收集，在文章页“源码”区块展示：
  - 多文件时 tabs 按文件夹分组，每组左侧显示文件夹名，根目录文件归入“当前目录”组；
  - 代码块标题显示文件相对路径，支持切换、单文件复制、带路径的“全部复制”和打开原始文件。

所以新增内容时，只要把 Markdown 和配套源码放进 `知识库/` 对应目录即可，刷新页面就会出现，无需改任何配置文件。

## 站点外观

`config.json` 里的 `site` 只控制品牌信息（标题、强调色、是否渲染 Mermaid）：

```json
{
  "site": {
    "title": "计算机知识库",
    "subtitle": "",
    "description": "",
    "footer": "",
    "accent": "#0f766e",
    "mermaid": true
  }
}
```

`subtitle`、`description`、`footer` 留空时，会按实际扫描结果自动生成。

## 目录约定

```text
.
├── config.json          # 仅站点品牌信息（可选）
├── index.html           # 页面骨架
├── styles.css           # 样式
├── app.js               # 渲染、路由、搜索逻辑
├── server.js            # 静态服务器 + 目录自动扫描
└── 知识库/               # 学习资料，目录即配置
```

支持的特性：首页分类总览与最近更新、按目录分组、Markdown 渲染与目录、源码按文件夹分组展示与复制、全文搜索、明暗主题、移动端侧边栏。
