## 一、基础概念（12 题）

### 1.1 CSS 盒模型有几种？区别？

两种：

- **content-box**（默认）：`width` 只算内容区，加 padding/border 会让盒子实际变宽。
- **border-box**：`width` 包含 content + padding + border，所见即所得。

```css
*, *::before, *::after { box-sizing: border-box; }
```

生产环境统一 border-box，避免布局错位。

### 1.2 CSS 选择器优先级怎么算？

四元组 `(a, b, c, d)`，从左到右逐位比较：

- `a` = 是否行内 style（0 或 1）
- `b` = ID 选择器个数
- `c` = class / 属性 / 伪类个数
- `d` = 元素 / 伪元素个数

```css
#nav .item a { }   /* (0,1,1,1) 胜出 */
.list .item a { }  /* (0,0,2,1) */
a { }              /* (0,0,0,1) */
```

同优先级时后写胜出，`!important` 凌驾一切（慎用）。

### 1.3 行内 style 与 !important 谁优先？

`!important` 高于行内 style。优先级从高到低：

1. 用户样式表 `!important`
2. 作者样式表 `!important`
3. 作者样式表行内 style
4. 作者样式表普通规则
5. 用户样式表普通规则
6. 浏览器默认样式

### 1.4 `display: none` vs `visibility: hidden` vs `opacity: 0`？

| 特性 | display:none | visibility:hidden | opacity:0 |
|---|---|---|---|
| 占位 | 不占 | 占 | 占 |
| 子元素可单独显示 | 否 | 是（子 visibility:visible 可见） | 否 |
| 事件响应 | 否 | 否 | 是 |
| 读屏器 | 跳过 | 跳过 | 朗读 |
| 触发回流 | 是 | 否（仅重绘） | 否（仅合成） |

### 1.5 块级、行内、行内块区别？

- 块级：独占一行，可设宽高（div/p/h1）。
- 行内：不换行，宽高无效（span/a）。
- 行内块：不换行，可设宽高（img/button）。

行内元素设上下 padding/margin 会"撑开"但不影响布局（视觉溢出）。

### 1.6 reset.css vs normalize.css？

- **reset.css**：暴力清零所有默认样式（margin:0、h1 字号清零），从零开始搭。
- **normalize.css**：保留有用的默认样式，修正浏览器差异（如各浏览器 h1 字号统一）。

现代项目多用 normalize 或 Tailwind 的 Preflight，reset 太"野蛮"。

### 1.7 CSS 单位 px/em/rem/vw 区别？

| 单位 | 相对什么 | 用法 |
|---|---|---|
| px | 绝对像素 | 边框、固定尺寸 |
| em | 父元素字号 | 谨慎，嵌套会乘积放大 |
| rem | 根元素字号 | 排版首选，统一可控 |
| vw/vh | 视口宽/高 1% | 全屏布局 |
| vmin/vmax | 视口较小/较大边 | 横竖屏适配 |

### 1.8 ::before 和 :before 区别？

写法等价，但 CSS3 规范要求伪元素用双冒号 `::before`，伪类用单冒号 `:hover`。旧浏览器（IE8）只认单冒号，现代项目用双冒号更规范。

### 1.9 为什么伪元素必须有 content？

伪元素本身没有内容，`content` 属性生成它的"虚拟文本/虚拟节点"。哪怕 `content: ""` 也是显式声明"这是一个空节点"，否则不渲染。常见用法：图标、清除浮动、装饰线。

### 1.10 calc() 能做什么？什么不能放？

```css
.aside { width: calc(100% - 200px); }
.font { font-size: calc(1rem + 2vw); }
```

可混合不同单位运算，但**运算符两边必须有空格**（`-` 在无空格时会被解析为负号）。不能放变量之外的表达式如 `calc(var(--x) * var(--y))` 是可以的，但不能 `calc(50% - 10px / 0)`。

### 1.11 CSS 变量与 Sass 变量区别？

| 特性 | CSS 变量 | Sass 变量 |
|---|---|---|
| 时机 | 运行时 | 编译时 |
| 可继承 | 是 | 否 |
| JS 读写 | 是 | 否 |
| 主题切换 | 改 :root 即换肤 | 需重编译多份 |

主题切换用 CSS 变量，编译期常量用 Sass。

### 1.12 CSS 注释有几种？

```css
/* 普通注释 */
/*! 关键注释：压缩工具保留 */
```

Sass 还有 `//` 单行注释（不输出到编译结果）。

## 二、布局（15 题）

### 2.1 清除浮动有几种方法？

1. 父加 `display: flow-root`（推荐，无副作用）。
2. 父加 `overflow: hidden`（会裁剪溢出内容，慎用）。
3. 末尾加 `::after { content: ""; display: block; clear: both; }`（经典 clearfix）。
4. 父也浮动（不推荐，污染父级）。

现代项目能用 flex/grid 就别用 float，float 仅作文字环绕。

### 2.2 BFC 是什么？触发条件？应用？

BFC = 块级格式化上下文，一块独立渲染区，内部元素不影响外部。
触发：

- `overflow` 不为 `visible`
- `float` 不为 `none`
- `display: flow-root / flex / grid / inline-block / table-cell`
- `position: absolute / fixed`

应用：清浮动、阻止 margin 合并、阻止文字环绕浮动。

### 2.3 margin 合并规则？如何阻止？

相邻块级元素上下 margin 取大值合并，父子无 border/padding 时子的 margin-top 会"穿透"到父外。
阻止：

- 父加 `overflow: hidden` / `padding-top: 1px` / `border-top: 1px solid transparent`
- 父加 `display: flow-root`（推荐）
- 父或子加 BFC

### 2.4 Flex 的主轴/交叉轴怎么判断？

由 `flex-direction` 决定：

- `row`（默认）：主轴水平向右，交叉轴垂直向下。
- `column`：主轴垂直向下，交叉轴水平向右。

`justify-content` 永远作用在主轴，`align-items` 永远作用在交叉轴。

### 2.5 flex: 1 等价什么？

`flex: 1 1 0%`，即 flex-grow 1 / flex-shrink 1 / flex-basis 0%。剩余空间按 grow 等分，basis 为 0 表示不占基准尺寸。

### 2.6 flex: 1 / auto / none 区别？

| 写法 | 等价 | 含义 |
|---|---|---|
| `flex: 1` | `1 1 0%` | 等分剩余空间 |
| `flex: auto` | `1 1 auto` | 等分，但先按内容尺寸 |
| `flex: none` | `0 0 auto` | 不伸不缩，按内容尺寸 |
| `flex: 0` | `0 0 0%` | 不伸不缩，尺寸为 0 |

### 2.7 Grid 与 Flex 怎么选？

- **Flex 一维**：单行或单列排列，导航条、按钮组、卡片横排。
- **Grid 二维**：行和列同时管理，整页布局、表格状结构。

复杂整页用 Grid，组件内排列用 Flex。

### 2.8 实现元素水平垂直居中（至少 4 种）

```css
/* 1. Flex 万能 */
.parent { display: flex; justify-content: center; align-items: center; }

/* 2. Grid 简写 */
.parent { display: grid; place-items: center; }

/* 3. 绝对定位 + transform（子尺寸未知） */
.child { position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%); }

/* 4. 绝对定位 + margin auto（子有尺寸） */
.child { position: absolute; inset: 0; margin: auto; width: 100px; height: 100px; }

/* 5. 绝对定位 + 负 margin（子有尺寸） */
.child { position: absolute; top: 50%; left: 50%; width: 100px; height: 100px; margin: -50px 0 0 -50px; }
```

### 2.9 position 各值的参考系？

| 值 | 参考系 | 脱离文档流 |
|---|---|---|
| static | 默认流 | 否 |
| relative | 自身原位置 | 否 |
| absolute | 最近非 static 祖先 | 是 |
| fixed | 视口（祖先无 transform/filter 时） | 是 |
| sticky | 滚动阈值前 relative，到后变 fixed | 否 |

**坑**：父级有 `transform / filter / will-change` 时，`fixed` 会改以该父为参考系。

### 2.10 sticky 失效的常见原因？

- 父级 `overflow: hidden / auto` 会"提前释放"sticky。
- 父级高度不够（sticky 没有滚动空间）。
- 未指定 `top / bottom / left / right` 任一阈值。

### 2.11 两栏布局（左定宽右自适应）几种方案？

```css
/* 1. Flex */
.row { display: flex; }
.left { width: 200px; }
.right { flex: 1; }

/* 2. Grid */
.row { display: grid; grid-template-columns: 200px 1fr; }

/* 3. float + margin */
.left { float: left; width: 200px; }
.right { margin-left: 200px; }

/* 4. 绝对定位 */
.left { position: absolute; left: 0; width: 200px; }
.right { margin-left: 200px; }
```

### 2.12 三栏布局（圣杯/双飞翼）？

经典圣杯：左右定宽 + 中间自适应，中间优先渲染。

```html
<div class="container">
  <div class="main">中</div>
  <div class="left">左</div>
  <div class="right">右</div>
</div>
```

```css
.container { padding: 0 200px 0 200px; }
.main { float: left; width: 100%; }
.left  { float: left; width: 200px; margin-left: -100%; position: relative; left: -200px; }
.right { float: left; width: 200px; margin-left: -200px; position: relative; right: -200px; }
```

现代推荐直接用 Grid：

```css
.container { display: grid; grid-template-columns: 200px 1fr 200px; }
```

### 2.13 实现一个等高布局

```css
.row { display: flex; }   /* flex 默认 align-items: stretch，等高 */
```

或 Grid `align-items: stretch`（默认）。float + 等高是上个世纪的负 margin 技巧，已淘汰。

### 2.14 实现 1px 边框（移动端高清屏）

设备像素比 2-3 时，1px CSS 边框实际占 2-3 物理像素，看起来偏粗。方案：

```css
.border-1px::after {
  content: ""; position: absolute; left: 0; bottom: 0; width: 100%; height: 1px;
  background: #ccc; transform: scaleY(0.5); transform-origin: 0 0;
}
```

### 2.15 实现三角形

```css
.triangle-up {
  width: 0; height: 0;
  border-left: 50px solid transparent;
  border-right: 50px solid transparent;
  border-bottom: 50px solid #6366f1;
}
```

利用 border 相交处是斜边的特性，三边透明一边有色即得三角形。

## 三、性能（8 题）

### 3.1 回流 vs 重绘？哪些操作触发？

- **回流 reflow**：元素几何（位置/尺寸）变化，重新布局。改 width/top/margin/font-size、增删 DOM、resize。
- **重绘 repaint**：元素外观变化，不重新布局。改 color/background/visibility。

回流一定伴随重绘，重绘不一定回流。**改 transform/opacity 走合成层，两者都不触发**。

### 3.2 如何减少回流？

- 用 transform 替代 top/left 做动画。
- 批量改样式：改 class 而非逐个 style 属性。
- 离线操作 DOM：先 `display: none` 或 DocumentFragment 构建完再插入。
- 避免逐条读取布局属性（offsetHeight 会强制同步布局）。
- 大列表用 `content-visibility: auto`。

### 3.3 will-change 是什么？什么时候用？

告诉浏览器"这个元素即将变化"，提前为之创建独立合成层。仅对即将发生的动画有用，**不要常驻**（占用 GPU 内存）。

```css
.modal { will-change: transform; }  /* 即将开启动画 */
.modal.closed { will-change: auto; } /* 关闭后释放 */
```

### 3.4 CSS 动画 vs JS 动画？

- CSS 动画：跑在合成线程，不阻塞主线程，性能好，但控制逻辑简单。
- JS 动画：可编程性强（缓动函数、状态联动），但跑主线程，长任务会卡。

优先 CSS（transform/opacity），复杂交互用 requestAnimationFrame 驱动 JS。

### 3.5 transition 写在 hover 里为什么移出没过渡？

```css
/* 不好 */
.btn:hover { transition: all 0.3s; background: #6366f1; }

/* 好 */
.btn { transition: background 0.3s; }
.btn:hover { background: #6366f1; }
```

transition 写在起始状态，进入和移出都有过渡。写在 hover 内只有进入有，移出瞬间跳变。

### 3.6 GPU 加速的属性有哪些？

- `transform`
- `opacity`
- `filter`
- `will-change`

这些属性变化走合成层，不触发布局/绘制。配合 `transform: translateZ(0)` 强制开启合成层。

### 3.7 @import 为什么慢？

```css
@import url("a.css");  /* 串行：等当前 CSS 下载解析后才请求 a.css */
```

浏览器解析到 @import 才发起新请求，串行加载。改用 `<link rel="stylesheet">` 并行加载，或打包合并。

### 3.8 Critical CSS 是什么？

首屏关键样式：内联到 HTML 的 `<head>`，让首屏立即渲染不必等外部 CSS。其余 CSS 异步加载。

```html
<style>/* 首屏内联 CSS */</style>
<link rel="preload" href="/full.css" as="style" onload="this.rel='stylesheet'">
```

## 四、响应式与现代特性（10 题）

### 4.1 媒体查询怎么写？移动优先是什么？

```css
/* 默认小屏，逐步增强 */
.card { padding: 12px; }
@media (min-width: 768px)  { .card { padding: 20px; } }
@media (min-width: 1200px) { .card { padding: 32px; } }
```

移动优先：默认样式给小屏，媒体查询加 `min-width` 逐级增强。优于桌面优先（默认大屏，加 max-width 降级）。

### 4.2 容器查询与媒体查询区别？

```css
.card-wrap { container-type: inline-size; }
@container (min-width: 400px) {
  .card { display: grid; grid-template-columns: 1fr 2fr; }
}
```

媒体查询按**视口**适配，容器查询按**自身容器**适配。组件在不同位置宽度不同时，容器查询才是真正组件级响应式。

### 4.3 实现自适应字号

```css
h1 { font-size: clamp(1.5rem, 4vw, 2.5rem); }
```

最小 1.5rem，最大 2.5rem，中间随视口 4vw 变化。兼顾可读性与自适应。

### 4.4 响应式图片有几种方案？

```css
/* 1. max-width 流式 */
img { max-width: 100%; height: auto; }

/* 2. aspect-ratio 保持比例 */
.box { aspect-ratio: 16/9; }
```

HTML 端用 `<picture>` + `<img srcset>` 按屏幕选不同图源。

### 4.5 实现暗色主题

```css
:root { --bg: #fff; --text: #1a1a1f; }
:root[data-theme="dark"] { --bg: #18181b; --text: #f4f4f5; }

body { background: var(--bg); color: var(--text); }

/* 跟随系统 */
@media (prefers-color-scheme: dark) {
  :root:not([data-theme]) { --bg: #18181b; --text: #f4f4f5; }
}
```

切换 class/data 属性即可换肤，不重载页面。

### 4.6 :is / :where / :has 区别？

```css
:is(header, main, aside) a { }   /* 特异性 = 参数最高 */
:where(header, main, aside) a { } /* 特异性 = 0，便于覆盖 */
div:has(> img) { }               /* 父选择：含直接子 img 的 div */
```

`:has` 是 2023 才广泛支持的"父选择器"，能根据子状态选父。

### 4.7 实现一个不超过 2 行的省略

```css
.lines-2 {
  display: -webkit-box;
  -webkit-line-clamp: 2;
  -webkit-box-orient: vertical;
  overflow: hidden;
}
```

单行更简单：

```css
.ellipsis { white-space: nowrap; overflow: hidden; text-overflow: ellipsis; }
```

### 4.8 CSS 原生嵌套怎么用？

```css
.card {
  padding: 16px;
  & .title { font-weight: 600; }
  &:hover { box-shadow: 0 4px 12px rgba(0,0,0,.1); }
}
```

2023+ 浏览器原生支持，语法与 Sass 类似但 `&` 必须显式写。

### 4.9 aspect-ratio 怎么用？

```css
.video { aspect-ratio: 16/9; width: 100%; }
.avatar { aspect-ratio: 1; height: 48px; }
```

保持固定宽高比，省去 padding-bottom hack。

### 4.10 @layer 是什么？

```css
@layer base, components, utilities;

@layer base {
  h1 { font-size: 2rem; }
}
@layer utilities {
  .text-center { text-align: center; }
}
```

显式声明层叠层，控制不同来源样式的优先级（后声明的 layer 优先）。解决第三方库样式难以覆盖的问题。

## 五、手写题与场景题（5 题）

### 5.1 写一个圣杯/双飞翼的现代等价（三栏 Grid）

```css
.layout {
  display: grid;
  grid-template-columns: 200px 1fr 200px;
  grid-template-areas: "header header header" "left main right" "footer footer footer";
  min-height: 100vh;
}
.header { grid-area: header; }
.left   { grid-area: left; }
.main   { grid-area: main; }
.right  { grid-area: right; }
.footer { grid-area: footer; }

@media (max-width: 768px) {
  .layout { grid-template-columns: 1fr; grid-template-areas: "header" "main" "footer"; }
  .left, .right { display: none; }
}
```

### 5.2 实现一个固定头 + 吸顶导航 + 滚动内容

```css
body { margin: 0; }
.header { position: fixed; top: 0; left: 0; right: 0; height: 60px; background: #fff; z-index: 100; }
.nav    { position: sticky; top: 60px; background: #f5f5f5; z-index: 99; }
.main   { margin-top: 60px; }  /* 抵消 fixed 占位 */
```

### 5.3 实现 0.5px 边框

```css
.hairline { position: relative; }
.hairline::after {
  content: ""; position: absolute; left: 0; bottom: 0; width: 100%; height: 1px;
  background: #ccc; transform: scaleY(0.5); transform-origin: 0 0;
}
```

### 5.4 实现一个 Loading 旋转图标

```css
.loader {
  width: 32px; height: 32px;
  border: 3px solid #e5e5e7; border-top-color: #6366f1;
  border-radius: 50%;
  animation: spin 0.8s linear infinite;
}
@keyframes spin { to { transform: rotate(360deg); } }

@media (prefers-reduced-motion: reduce) {
  .loader { animation: none; }
}
```

### 5.5 场景：列表项之间加分割线但最后一项不要

```css
.list > .item + .item { border-top: 1px solid #e5e5e7; }
/* 或 */
.list > .item:not(:last-child) { border-bottom: 1px solid #e5e5e7; }
```

第一种用相邻兄弟选择器，无最后一项问题；第二种需排除 last-child。

## 六、生产环境最佳实践 Checklist

### 6.1 布局与盒模型

- 全局 `box-sizing: border-box`
- 优先 Flex / Grid，少用 float（仅文字环绕）
- 不用 table 做布局
- 用 `gap` 替代 margin 拼接间距

### 6.2 选择器与优先级

- 不滥用 ID 选择器
- 不滥用 `!important`
- 选择器嵌套 ≤ 3 层
- 基础样式用 `:where()` 便于覆盖

### 6.3 性能

- 动画用 `transform` / `opacity`
- 大列表加 `content-visibility: auto`
- 图片合理尺寸 + webp + lazy
- 不用 `@import`，外部 CSS 用 `<link>`

### 6.4 主题与可访问

- 颜色用 CSS 变量统一管理
- 暗色主题 + `prefers-color-scheme` 跟随系统
- 对比度 ≥ 4.5:1
- 动效尊重 `prefers-reduced-motion`
- 焦点样式不删，用 `:focus-visible`

### 6.5 响应式

- 移动优先，媒体查询用 `min-width`
- 触摸目标 ≥ 44×44px
- `:hover` 用 `@media (hover: hover)` 限定
- 安全区域 `env(safe-area-inset-*)`

## 七、一句话总纲

> CSS 面试的三个层次：**第一层问"是什么"**（盒模型、选择器优先级、position 取值），**第二层问"怎么排"**（居中、两栏三栏、BFC、Flex/Grid 选型），**第三层问"怎么快"**（回流重绘、GPU 加速、Critical CSS、容器查询）。能从"居中四种写法"答到"为什么 transform 比 top 快"，就是高级前端对 CSS 的认知。
