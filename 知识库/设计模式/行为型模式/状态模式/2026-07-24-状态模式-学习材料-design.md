# 状态模式学习材料 — 设计规格

日期：2026-07-24  
范围：`server_study/设计模式/状态模式/`  
对齐参考：`设计模式/访问者模式/`（精简版，无 evolve、无专题深挖）

---

## 1. 目标

为状态模式整理一套与访问者模式阅读体验对齐、但体量更小的 Go 学习材料，便于课堂「先读讲义 → 再 `go run .`」。

## 2. 已确认决策

| 项 | 结论 |
|----|------|
| 完整度 | 主讲义 + 一份可运行 `main.go`（无 `evolve/`） |
| 示范场景 | 订单状态（待支付 / 已支付 / 已发货 / 已取消） |
| 痛点对比 | 讲义不写 `if/switch` 演变；直接讲正统状态模式 |
| 讲义形态 | 方案 1：讲义内嵌完整示范代码，与 `main.go` 同构 |

## 3. 交付文件

```text
设计模式/状态模式/
├── 状态模式.md                              # 主讲义
├── main.go                                  # 可运行最终形态
├── go.mod                                   # module state-demo，go 1.21
└── 2026-07-24-状态模式-学习材料-design.md   # 本规格（可选保留）
```

明确不做：

- `evolve/step*`
- 类似「双重分派」的专题 md
- 讲义内「先错误写法再重构」长对比

## 4. 状态机

### 4.1 对外动作

- `Pay`：支付
- `Ship`：发货
- `Cancel`：取消

### 4.2 合法转换

| 当前状态 | Pay | Ship | Cancel |
|----------|-----|------|--------|
| Pending | → Paid | 拒绝 | → Cancelled |
| Paid | 拒绝 | → Shipped | → Cancelled |
| Shipped | 拒绝 | 拒绝 | 拒绝 |
| Cancelled | 拒绝 | 拒绝 | 拒绝 |

非法转换：不 panic，打印拒绝日志。

### 4.3 角色

| 角色 | 类型名 | 职责 |
|------|--------|------|
| Context | `Order` | 持有当前 `OrderState`，转发 `Pay/Ship/Cancel`，提供 `setState` |
| State | `OrderState` | 三种动作在当前状态下的行为接口 |
| ConcreteState | `PendingState` / `PaidState` / `ShippedState` / `CancelledState` | 实现转换或拒绝 |

## 5. 讲义结构（`状态模式.md`）

章节编号与访问者讲义同级风格（`## 1.` / `### 1.1`）：

1. **定义**：一句话意图；Context / State / ConcreteState；结构简图
2. **常见场景**：表格（订单、连接、审批流、播放器等）
3. **示范代码**：完整可抄代码（与 `main.go` 同构）；含状态转换说明与示例输出
4. **总结**：记住三件事、优缺点速查、选型一句话

文风：中文正文遵守 Markdown 结构规则（中英文空格、编号标题）；代码标识符英文。

## 6. `main.go` 演示脚本

1. 成功路径：`Pending → Pay → Paid → Ship → Shipped`，再 `Cancel`（拒绝）
2. 取消路径：新订单 `Pending → Cancel → Cancelled`，再 `Pay`（拒绝）

要求：切换与拒绝均有清晰中文日志；注释偏教学（角色、谁负责切状态），深度对齐访问者根目录 `main.go`。

## 7. 验收标准

- `cd 状态模式 && go run .` 可跑通，输出覆盖成功路径与拒绝路径
- 讲义可独立阅读，不依赖 evolve
- 不引入与规格无关的额外模式对比长文（策略模式可在总结里一句话带过，不展开）

## 8. 实现顺序（规格通过后）

1. 写 `go.mod`
2. 写 `main.go` 并本地运行核对输出
3. 写 `状态模式.md`（示范代码与运行结果与 `main.go` 一致）
