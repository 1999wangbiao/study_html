# 匿名函数（Anonymous Function）

> **匿名函数 = 没有名字的函数**。可赋给变量、作为参数传递、作为返回值返回、定义后立即调用。它是 Go 中"函数是一等公民"的最直接体现。

---

## 一、什么是匿名函数

```go
// 普通函数
func add(a, b int) int { return a + b }

// 匿名函数（赋值给变量）
add := func(a, b int) int { return a + b }
```

`func(a, b int) int { ... }` 这一整段就是匿名函数的字面量，它本身是一种**函数类型的值**。

函数本身是一种**类型**，可像 `int`、`string` 一样使用：

```go
var f func(int, int) int            // 声明函数类型变量
f = func(a, b int) int { return a + b }
result := f(1, 2)                   // 3

type Calc func(int, int) int        // 定义函数类型别名
func apply(x, y int, c Calc) int { return c(x, y) }
```

## 二、四种常见写法

| 写法 | 示例 | 用途 |
|------|------|------|
| 赋值给变量 | `double := func(n int) int { return n * 2 }` | 最常用 |
| 作为参数 | `each(nums, func(n int) int { return n + 1 })` | 回调 |
| 作为返回值 | `return func(x int) int { return base + x }` | 闭包/工厂 |
| 立即调用 IIFE | `v := func(a, b int) int { return a + b }(3, 4)` | 初始化/隔离作用域 |

IIFE（立即执行函数）常用于初始化变量、构造临时作用域：

```go
total := func() int {
    sum := 0
    for i := 1; i <= 100; i++ { sum += i }
    return sum
}() // 末尾 () 立即求值
```

## 三、匿名函数 + 闭包的关系

```go
a := func() {}                        // 匿名函数，但不引用外部变量 → 不是闭包
b := func() { fmt.Println(msg) }      // 匿名函数 + 引用外部变量 → 构成闭包
```

**匿名函数只有在引用了外部变量时才构成闭包。**

- 匿名函数：描述"没有名字的函数"这个**语法形态**。
- 闭包：描述"函数 + 它捕获的环境"这个**行为语义**。

## 四、常见用法

### 4.1 标准库回调

```go
sort.Slice(users, func(i, j int) bool { return users[i].Age > users[j].Age })

http.HandleFunc("/", func(w http.ResponseWriter, r *http.Request) {
    fmt.Fprintln(w, "Hello")
})
```

### 4.2 goroutine 入口

```go
go func() {
    for { /* 后台任务 */ }
}()
```

### 4.3 延迟清理（defer 闭包）

```go
f, _ := os.Open(path)
defer func() {
    f.Close()
    fmt.Println("file closed")
}()
```

### 4.4 隔离作用域（IIFE）

```go
val := func() int {
    // 私有临时计算
    return computeSomething()
}()
```

### 4.5 匿名函数递归

```go
var fib func(int) int          // 必须先声明变量类型
fib = func(n int) int {
    if n < 2 { return n }
    return fib(n-1) + fib(n-2) // 通过变量名引用自身
}
fmt.Println(fib(10)) // 55
```

注意：必须先 `var fib func(int) int` 再赋值，否则匿名函数内部无法引用一个尚未声明完的 `:=` 变量。

## 五、易错点

### 5.1 忘了立即调用，函数体没执行

```go
result := func(a, b int) int { return a + b }  // 没加 (a,b) → result 是函数，不是结果
result := func(a, b int) int { return a + b }(1, 2) // 正确 → 结果是 3
```

### 5.2 混淆"函数类型"与"调用结果"

```go
f := func() int { return 1 }   // f 是函数（func() int 类型）
v := func() int { return 1 }() // v 是 int，值为 1
```

`f` 和 `v` 类型完全不同，这是最容易迷惑的地方之一。

### 5.3 递归时变量未先声明

见上文 4.5，必须先 `var fib func(int) int`。

### 5.4 在循环里直接给切片/数组赋匿名函数

若匿名函数捕获循环变量，会踩循环变量陷阱（见闭包篇 5.3）。跨版本建议显式传参。

## 六、迷惑点辨析

### 6.1 匿名函数 = 闭包 吗？

**不完全是。** 匿名函数是语法形态；只有当它**引用外部变量**时才形成闭包。不引用的匿名函数只是普通函数值。

### 6.2 `:=` 与 `var` 声明函数的区别

```go
f := func() {}   // 自动推断类型，简洁
var f func()     // 显式声明，方便递归或先占位后赋值
```

### 6.3 传参是"传函数"还是"执行结果"？

传的是**函数本身（函数值）**，真正执行发生在被调方内部，不是传参那一刻。忘记这一点会以为传参时函数已经跑了一遍。

### 6.4 匿名函数能否访问外层局部变量？

**能**，这正是它形成闭包的机制。但读到的是**当前值**，而非定义后被重新赋值的"旧值"。

---

## 七、匿名函数高频自测

1. 匿名函数什么时候变成闭包？
   → **引用外部变量时**。
2. `result := func() int{...}` 和 `result := func() int{...}()` 的区别？
   → **前者是函数，后者是调用结果**。
3. 匿名函数递归为什么先要 `var fib func(int) int`？
   → 匿名函数没有名字，需先声明变量类型才能在函数体内引用自身。

---

## 八、一句话总结

> **匿名函数 = 没有名字的函数，是一等公民，可赋值、传参、返回、立即执行（IIFE）；引用外部变量时构成闭包。** 它是标准库回调、goroutine、defer 清理、函数工厂的基础载体。
