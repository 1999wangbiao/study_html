# Map 和 Slice 的区别

> **Slice 是有序的动态数组，强调索引访问和顺序；Map 是无序的键值对集合，强调通过 key 快速查找**。

---

## 一、核心区别

| 维度 | Slice | Map |
|------|-------|-----|
| 结构 | **有序**的动态数组 | **无序**的键值对集合 |
| 访问方式 | 索引 `s[i]` | 键 `m[key]` |
| 顺序 | **保持插入顺序** | **遍历顺序不固定**（哈希分布 + 扩容影响） |
| 查找复杂度 | O(n) 线性查找 | **O(1)** 哈希查找 |
| 适合场景 | 按顺序存储同类型元素 | 通过 key 快速操作数据 |
| 底层 | 指针 + 长度 + 容量 | 桶数组 + 溢出桶（哈希表） |

---

## 二、怎么选

- **需要顺序、索引、切片操作**（遍历、截取、追加）→ 用 **slice**；
- **需要 key-value 快速查找、去重、关联数据** → 用 **map**；
- 两者可组合：`[]map[string]int`、`map[string][]int` 等。

---

## 三、一句话总结

> **Slice 有序重顺序（索引 + 连续性），Map 无序重查找（key 哈希 O(1)）**。按"要不要顺序、要不要按 key 查"来选。
