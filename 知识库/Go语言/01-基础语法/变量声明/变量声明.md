# Go 语言 new / make / var / 短声明

> **new 分配内存返回指针；make 只用于 slice/map/channel 并返回引用本身；var 显式声明自动零值；短声明在函数内自动推断类型**。四者的核心区别在"返回什么"和"初始化到什么程度"。

---

## 一、对比总览

| 方式 | 作用 | 返回 | 初始化 | 使用位置 |
|------|------|------|--------|----------|
| `new(T)` | 为类型分配内存 | **指针 `*T`** | 零值 | 任意 |
| `make(T)` | 创建 slice/map/channel | **引用本身** | 初始化底层结构 | 仅这三种类型 |
| `var` | 声明变量 | 变量本身 | 自动零值 | 包级/函数级 |
| `:=` 短声明 | 声明并初始化 | 变量本身 | 显式初值 | 仅函数内 |

---

## 二、逐个详解

### new

- 为某种类型**分配内存**，返回该类型的**指针**；
- 分配内存，**不初始化**（除了零值）。

```go
p := new(int)   // p 是 *int，*p == 0
```

### var

- 声明变量（可以带初始值，也可以不带）；
- 不赋值时，自动初始化为**零值**（`0`、`""`、`nil` 等）；
- 适用于**包级变量**或需要**显式声明类型**的地方。

```go
var a int      // 0
var s string   // ""
var m map[string]int // nil
var x = 10     // 带初值
```

### make

- **只用于创建 slice、map、channel**，并完成初始化；
- make 会分配内存并**初始化底层数据结构**；
- 返回的是**引用类型本身（不是指针）**。

```go
s := make([]int, 3, 5)   // 切片
m := make(map[string]int) // map
c := make(chan int, 10)  // 带缓冲 channel
```

### 短声明变量（`:=`）

- 声明并初始化变量，**只能在函数内使用**；
- 自动推断变量的类型。

```go
n := 42       // int
name := "go"  // string
f := func() {} // func()
```

---

## 三、易错点

1. **`new` vs `make` 混淆**：`new` 返回指针、不初始化内部结构；`make` 返回引用本身、初始化底层结构。`new(map[string]int)` 得到的是 nil map 的指针，不能直接赋值。
2. **`var` 与 `:=` 混淆**：`:=` 只能在函数内；包级只能用 `var`。
3. **`:=` 要求左侧至少有一个新变量**：`a, b := 1, 2` 后再 `a, c := 3, 4` 是合法的（c 是新变量），但 `a := 1` 再 `a := 2` 会编译错误。

---

## 四、高频自测

1. `new(T)` 返回什么？
   → **`*T` 指针，指向零值**。
2. `make` 能用在哪三种类型上？
   → **slice、map、channel**。
3. 包级变量能用 `:=` 吗？
   → **不能**，只能用 `var`。

---

## 五、一句话总结

> **new = 分配零值内存返回指针；make = 初始化引用类型返回本身；var = 显式声明（自动零值）；短声明 = 函数内声明 + 类型推断**。记忆口诀：**new 拿指针，make 只做三种容器，var 稳，`:=` 快**。
