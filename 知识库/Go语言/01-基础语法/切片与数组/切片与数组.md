# Go 语言切片（slice）与数组的区别

> **数组长度固定、值类型；切片长度可变、引用类型**。切片底层只含三个信息（指针、长度、容量），扩容遵循"小容量翻倍、大容量 1.25 倍"的规则，且多个切片可能共享同一底层数组。

---

## 一、数组（Array）

- 数组的**长度在初始化时就定好，一旦声明就不能改变**；
- **值类型**：数组赋值或作为函数参数时，会**拷贝整个数组**（而非引用），修改副本不会影响原数组。

```go
a := [3]int{1, 2, 3}   // 固定长度
b := a                  // 拷贝整个数组
b[0] = 99               // a 不受影响
```

---

## 二、切片（Slice）

**切片本身仅包含三个信息**：指向底层数组的**指针**、**长度（len）**、**容量（cap）**。

切片是对数组的**动态视图**，本身不存储数据，而是引用底层数组的一段连续元素：

- 长度是**动态可变**的；
- 具有**容量（cap）**和**长度（len）**两个特性；
- **引用类型**：切片赋值或作为函数参数时，传递的是引用（指针），修改切片会影响底层数组和其他引用同一数组的切片。

```go
type slice struct {
    ptr *array // 指向底层数组
    len int    // 长度
    cap int    // 容量
}
```

---

## 三、切片扩容机制

当 `append` 导致切片长度超过容量时，Go 会**创建一个新的底层数组**并复制原数据，此时切片指向新数组，原数组若无人引用则被 GC 回收。

扩容策略（Go 1.18+ 实际规则）：

- 小容量（`newcap < 256`）：**翻倍**（×2）；
- 大容量（`newcap >= 256`）：约 **1.25 倍** 增长。

```go
newcap := oldCap

if newcap < 256 {
    newcap *= 2
} else {
    for newcap < required { // required 为追加后需要的容量
        newcap += (newcap + 3*256) / 4
    }
}
```

> 一句话：**1024（实际是 256）之前约 2 倍，之后约 1.25 倍**。

---

## 四、切片的"共享底层数组"

多个切片引用同一底层数组时，**修改一个切片可能影响其他切片**。若需独立修改，可使用 `copy` 创建新切片：

```go
s1 := []int{1, 2, 3}
s2 := make([]int, len(s1))
copy(s2, s1) // s2 是独立切片，修改不影响 s1
```

### 经典示例：子切片共享底层数组

```go
package main

import "fmt"

func main() {
    // 创建一个底层数组并生成切片
    numbers := []int{1, 2, 3, 4, 5}

    // 从原切片创建子切片（共享底层数组）
    subSlice := numbers[1:3] // 包含元素 [2, 3]
    fmt.Println("原始子切片:", subSlice) // 输出: [2 3]

    // 错误操作：修改子切片，预期只影响子切片
    subSlice[0] = 99
    fmt.Println("修改后的子切片:", subSlice) // 输出: [99 3]

    // 意外结果：原始切片也被修改了
    fmt.Println("被影响的原始切片:", numbers) // 输出: [1 99 3 4 5]

    // 更隐蔽的错误：append 扩容前的修改仍会影响原始数组
    subSlice = append(subSlice, 6)
    subSlice[1] = 88
    fmt.Println("再次修改的子切片:", subSlice) // 输出: [99 88 6]
    fmt.Println("再次被影响的原始切片:", numbers) // 输出: [1 99 88 4 5]
}
```

> 关键点：**只要 append 还没触发扩容，子切片就和原切片共享底层数组**；扩容后才分道扬镳。

## 五、for range 的地址变化

**Go 1.21 版本前**：`for range` 会声明一个循环变量（如 `v`），每次迭代把当前元素的值**复制**到这个循环变量中。这个循环变量在整个循环过程中是**同一个变量，地址始终不变**，只是值在每次迭代被更新。

**Go 1.21 版本后**：`range` 每次迭代**创建新的循环变量**。

```go
// 1.21 前经典写法：显式创建新变量避免闭包共享
for _, v := range arr {
    v := v // 创建新变量
    go func() {
        fmt.Println(v)
    }()
}
```

## 六、数组 vs 切片对比

| 维度 | 数组 | 切片 |
|------|------|------|
| 长度 | 固定 | **动态** |
| 类型 | 值类型 | **引用类型** |
| 传参 | 拷贝整个数组 | 传引用（指针+len+cap） |
| 底层 | 直接存数据 | **引用底层数组** |
| 扩容 | 不支持 | 2 倍 / 1.25 倍 |

---

## 七、高频自测

1. 切片底层结构包含哪三个信息？
   → **指向底层数组的指针、长度（len）、容量（cap）**。
2. 扩容规则？
   → **256 之前翻倍，之后约 1.25 倍**。
3. 修改子切片会影响原切片吗？
   → **会（未扩容前共享底层数组）**；用 `copy` 可隔离。
4. 1.21 前后 for range 循环变量的地址？
   → **1.21 前是同一变量地址不变，1.21 后每次迭代是新变量**。

---

## 八、一句话总结

> **数组定长、值类型；切片可变长、引用类型，由"指针 + len + cap"三元组描述底层数组的一段视图**。扩容小翻倍、大 1.25 倍；共享底层数组是切片最大的坑，也是最大的复用优势。
