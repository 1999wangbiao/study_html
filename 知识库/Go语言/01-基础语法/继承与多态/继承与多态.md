# Go 如何实现继承和多态

> **Go 没有 class 和继承关键字，但通过"结构体组合（匿名嵌套）"实现继承、通过"接口（隐式实现）"实现多态**。哲学是"组合优于继承"。

---

## 一、实现"继承"：结构体组合（匿名嵌套）

Go 采用"组合"思想，通过**结构体匿名嵌套**实现代码复用，模拟继承的效果。**外层结构体可以直接访问内层结构体的字段和方法，也能重写方法**。

```go
type Animal struct {
    Name string
}

func (a Animal) Speak() string {
    return "..." // 动物默认叫声
}

// Dog 匿名嵌套 Animal → 继承其字段和方法
type Dog struct {
    Animal
}

// 重写方法：多态的关键
func (d Dog) Speak() string {
    return "汪汪"
}

func main() {
    d := Dog{Animal: Animal{Name: "旺财"}}
    fmt.Println(d.Name)   // "旺财"（访问内嵌字段）
    fmt.Println(d.Speak()) // "汪汪"（重写后）
}
```

- **匿名嵌套**：`Dog` 里放 `Animal`（不带名字）就能"继承"它的字段和方法；
- **方法重写**：外层定义同名方法即可覆盖内层。

---

## 二、实现"多态"：接口（隐式实现）

Go 的接口是**隐式实现**的（无需 `implements` 关键字），只要类型实现了接口的所有方法，就属于该接口类型。这种特性天然支持多态：**同一接口变量可存储不同实现，调用方法时自动适配具体类型**。

```go
// 定义接口
type Speaker interface {
    Speak() string
}

// 不同类型都实现了 Speak → 都属于 Speaker
type Dog struct{}
func (d Dog) Speak() string { return "汪汪" }

type Cat struct{}
func (c Cat) Speak() string { return "喵喵" }

func main() {
    var s Speaker
    s = Dog{}
    fmt.Println(s.Speak()) // "汪汪"

    s = Cat{}
    fmt.Println(s.Speak()) // "喵喵"（同一接口，不同行为 = 多态）
}
```

---

## 三、组合 vs 传统继承

| 维度 | 传统 OOP 继承 | Go 组合 + 接口 |
|------|---------------|----------------|
| 关键字 | extends / implements | **匿名嵌套 + 接口** |
| 复用方式 | 继承父类 | **组合嵌入** |
| 多态 | 重写方法 | **接口隐式实现** |
| 耦合 | 强（父子紧耦合） | **弱（按能力组合）** |
| 设计哲学 | 继承优先 | **组合优于继承** |

---

## 四、高频自测

1. Go 怎么实现"继承"？
   → **结构体匿名嵌套（组合）**，外层可直接访问内层字段和方法。
2. Go 怎么实现多态？
   → **接口隐式实现**：类型实现了接口全部方法即属于该接口，同接口变量可存不同实现。
3. Go 为什么不提供 class 继承？
   → 遵循 **"组合优于继承"** 的设计哲学，耦合更低、更灵活。

---

## 五、一句话总结

> **Go 用"结构体组合（匿名嵌套）"模拟继承、用"接口（隐式实现）"实现多态**——不需要 extends/implements 关键字，类型天然满足接口就自动"多态"。这既是复用手段，也是 Go"组合优于继承"哲学的体现。
